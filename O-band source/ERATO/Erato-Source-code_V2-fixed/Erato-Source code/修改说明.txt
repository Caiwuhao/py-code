一、(c) 的实际计算
1. 从 data260123-g(2)-2.txt 读取全部 500 个时间 bin 与计数。
2. 按 g2_config.json 中列出的窗口逐 bin 求和。窗口为 53–55、119–121、185–187、251–253、316–318、382–384、448–450（含两端）。它们对应之前采用的七个 3-bin 积分；没有把峰面积作为绘图输入。
3. 每个积分减去此前测得的背景 293.7 ± 4.5，再除以六个扣背景后旁峰的平均值。
4. 中央柱高度就是 g2；纯度由 (g2−1)×100% 自动计算，误差也由同一次积分传播得到。
5. 背景是有来源的测量输入，单独保存在 g2_config.json 中；来源为博士论文 Sec. 5.4.7、纸面 p.85 / PDF p.99、Eq.(5.22)。现有附件没有可运行的旧背景估计代码，压缩长截图无法可靠恢复其 mask 和算法。本程序不声称从原始直方图重新估计了这个背景，也没有用目标纯度反推背景。
