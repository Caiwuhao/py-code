# QUTE 3.5 µm 复现与数值验证记录

## 1. 验收口径

本次先做 QUTE Table B1 中 3.5 µm 的性能基准：pump 1.75 µm、signal/idler
3.5 µm、名义 30 mm、周期 15.497 µm、1935 个周期。目标参考纯度为
0.997571，泵浦强度 FWHM 约 3.8 nm。

这不是原论文 duty 向量的逐元素重现：没有拿到原论文最终 1935 个 duty
数值和完整随机状态。基准含义是：在明确相同的波长、名义长度、评价窗口
和归一化约定下，给出能重跑、能独立检查的设计，并比较其性能。

主纯度按用户指定的 `Py_JSI_SPDC.py` 方法：以 `abs(PMF)` 构造 JSA，
200×200 均匀波长网格、两轴各 60 nm；JSA 作 L2 归一化，SVD 后
`P = sum(s**4)`。这保留了幅度相关性，但去除了 PMF 相位。
不能将其无条件称为包含谱相位的实际单光子纯度。因此新版另保存
`complex_purity_at_same_pump`，它以相同最优泵浦、相同网格保留复 PMF。
两个数不是两个不同的 SVD 算法，而是送进 SVD 的 JSA 不同。

## 2. 原结果为什么没有通过

从用户提供的 `output/run_3500nm/summary.json` 直接读取：

| 项目 | 用户上传结果 | 本次处理 |
|---|---|---|
| PSO duty 更新 | 48 粒子、200 次 | 单独记录粒子数、每轮迭代、轮数、累计迭代 |
| cost | complex_amplitude，0.0580153 | 论文比较先使用原 MATLAB 的归一化强度 MSE |
| 强制对称 | 开启 | 基准不强制，保留可选开关 |
| 泵浦 | 三种结构共用初始 3.759731 nm | 每种结构独立粗扫和细扫，再重算最优 JSA |
| JSA | 均匀频率取样、约 3459.82–3541.12 nm | 按 Py_JSI：均匀波长 3470–3530 nm |
| 谱相位 | 保留 | 主指标按 Py_JSI 取绝对值；另报复 PMF 指标 |
| erf 图 | 单独画出的解析累计 target | 换成实际三种晶体的泵浦优化曲线 |
| 坐标 | 旧绘图约定和自动刻度 | 横 signal，纵 idler，两轴同为 20 nm 主刻度 |
| 主程序默认值 | 用户已部分改为读取子模块 | 保留并补全该方式，没有恢复两套固定数值 |

0.0580153 是归一化复振幅误差，不等于“误差已经可以忽略”；开平方约为
24.1% 的相对 RMS 误差。旧图中的解析 erf 无论优化是否成功都会平滑，
它没有使用优化后的 duty，不能用来检验实际累计场是否接近 erf。

**不改旧 duty，只改评价口径并独立优化泵浦**，重新计算得到：

| 旧结构 | 最优 pump intensity FWHM / nm | Py_JSI 口径纯度 |
|---|---:|---:|
| periodic | 2.43 | 0.8643441293 |
| erf initial | 2.81 | 0.9801722933 |
| 旧 optimized | 3.21 | 0.9915235495 |

旧 optimized 原来报告的是 0.9755433990。这个对照表说明固定泵浦、窗口和
相位约定确实影响结果；但 0.991524 仍低于目标，不能仅改评价就声称通过。

还有一个只在**显式采用 Table B1 周期**时出现的坐标问题：原 Sellmeier
给出 15.50037044 µm，Table B1 是 15.497 µm。高斯目标应以所需的中心
波长对应的材料失配为零点，不能把所需波长和实际 grating 峰值强行等同。
用户上传的旧运行用的是 Sellmeier 周期，二者原本一致；因此不能把这一项
误说成旧运行失效的唯一原因。

## 3. 空间和频域如何严格对应

`A_j` 表示第 j 个**周期**内正 domain 的比例，不是第 j 个 domain 的长度：

\[
z_{0,j}=j\Lambda,\quad z_{m,j}=(j+A_j)\Lambda,\quad
z_{1,j}=(j+1)\Lambda.
\]

\[
\phi(k)=\frac1L\sum_j\left[
\int_{z_{0,j}}^{z_{m,j}}e^{-ikz}\,dz
-\int_{z_{m,j}}^{z_{1,j}}e^{-ikz}\,dz\right]
=\frac{\sum_j(e^{-ikz_{0,j}}-2e^{-ikz_{m,j}}+e^{-ikz_{1,j}})}{ikL}.
\]

这里 `k = k_p-k_s-k_i` 是材料失配。显式 `g(z)=±1` 已经包含 QPM，
不能再在积分指数中减去 grating vector。只有使用缓变非线性包络、已经
抽取一阶 grating 谐波时，才应配套使用残余失配 `q`。

高斯 target 则写为

\[
q=k(\lambda_s,\lambda_i)-k(\lambda_{s0},\lambda_{i0}),\quad
\phi_{tgt}(q)=e^{-q^2\sigma_z^2/2},\quad I_{tgt}=e^{-q^2\sigma_z^2}.
\]

这不是 FFT。它是对任意连续 domain wall 的解析积分，不存在把 FFT
数组下标错当成物理频率的问题。新版没有把正确的积分公式换成另一种
经验公式；新增的是明确的坐标、评价约定以及零失配的稳定 sinc 极限。

独立检查包括：

- 标准 50% duty 在一阶 QPM 峰处的幅度为 `2/pi`。
- 随机 duty 的逐 domain 端点积分与批量周期积分一致。
- 直接对每个 domain 的 cos/sin 用 `scipy.integrate.quad` 数值积分，包含
  正失配、负失配和零失配，与解析结果在约 1e-12 绝对误差内一致。
- 优化 cost 使用的 `pmf_batch()` 与绘图 `pmf_from_duties()` 在同一组
  物理失配点一致，排除了“优化和画图用了两套 Fourier 实现”。
- `custom-poling/utils/pmf.py` 的正指数约定与此式互为复共轭，差一个本程序
  明确采用的长度归一化；直接调用该源文件后最大绝对差约 4.8e-16。
- 从用户原文件提取并直接执行 `calculate_purity()` 后对比：JSA 最大绝对
  差约 1.4e-17，纯度差约 5.8e-16。

## 4. 参考资料中的不一致如何处理

QUTE 正文用 N 表示 domain 数，附录又写 N=1935；但 30 mm / 15.497 µm
约为 1935.86，而不是 967 个周期。thesis Listing C.1 明确写
`m=floor(30000/gamma)`，所以本程序明确记录 **1935 个周期、3870 个 nominal
domain 条目**。无最小 domain 模式可能有零长度条目，它们不是可制造尺寸。
实际长度是 1935×15.497 µm = 29.986695 mm，而不是偷偷改成刚好 30 mm。

thesis `arrayloop.m` 的循环索引、内部 wall 坐标与最终 `m*gamma` 端点之间
存在不自洽之处；论文还对 Eq. (4) 后的坐标表达作过勘误。为避免复制
因子二/量纲错误，采用正文积分定义、thesis 的周期数定义、`custom-poling`
的逐 domain 积分以及直接数值积分共同确定的几何，不逐字符照搬该循环。

本次同时遵守用户新要求：泵浦宽度用 `Py_JSI_SPDC.py` 的两级扫描，不再
逐行照搬 MATLAB 的两参数 pump PSO + patternsearch。因此“纯 PSO”准确
地指 **duty 优化仅用 PSO**，泵浦是独立的一维网格扫描；不是原始 MATLAB
整套随机过程的逐步复现。

## 5. 当前可验证结果

所有交付数值以相应 `output/` 中的 `summary.json`、duty 数组和扫描表为准。
随机 PSO 的 CPU/CuPy 随机数发生器和浮点求和次序不同，不保证跨设备获得
逐元素相同的 duty。GPU 正确性检查比较的是同一组 duty 的 PMF/cost。

### 5.1 两组纯 PSO 与参考指标

| duty 优化方式 | 最小 domain | 累计迭代 | 最优 pump FWHM / nm | Py_JSI 口径纯度 | 同泵浦保留复 PMF | 相对理想 PPLN 峰值强度 |
|---|---|---:|---:|---:|---:|---:|
| 纯 PSO | 不限制 | 1700 | 3.78 | 0.9976799765 | 0.9963825910 | 4.8816% |
| 纯 PSO | 500 nm | 1000 | 3.79 | 0.9964661428 | 0.9956712526 | 7.7639% |

第一行的 Py_JSI 幅度指标超过 Table B1 的 0.997571。第二行表明 500 nm
制造边界在当前模型和窗口下并不阻止达到 0.99。两组都没有梯度精修：
`polish_iterations=0`，算法字段为 `particle_swarm_optimization`。

**尚未通过的部分必须保留：** 两组复 PMF 纯度仍低于 Table B1 数值，且
尚未复现论文附录的宽窗口结果。因此本次是达到指定 Py_JSI 指标的性能
基准，不是“原论文全部数据已复现”，更不是无滤波实际源已验收。
无约束解含零长度 domain；峰值效率明显低于理想 PPLN，也说明单独拟合
归一化 PMF 强度不会自动保住亮度。

输出位置与 cost：

| 结果目录 | 最终 cost | 最短 domain / µm |
|---|---:|---:|
| `output/stage_1700` | 3.6242182723e-7 | 0 |
| `output/qute_500nm_pure_pso_1000` | 8.4524573006e-7 | 0.5（浮点误差约 5e-16） |

两组均独立优化了 periodic 和 erf initial 的泵浦。它们在此几何下分别为
2.42 nm / 0.8639774052 和 2.80 nm / 0.9801800828（带宽 / Py_JSI 纯度）；
不再把 optimized 的 3.78 或 3.79 nm 泵浦直接套给另外两种晶体。

### 5.2 精确 PSO 运行协议

固定：pump 1.75 µm、signal/idler 3.5 µm、周期 15.497 µm、名义 30 mm，
`sigma_z=6 mm`，1935 duty 变量；24 粒子，seed=7，不强制对称；
`legacy_intensity`，601 个点、60 nm 能量守恒波长切片；每 cycle 100 次
更新，cycle 间噪声衰减 0.6。其余 PSO 系数见交付 `PSOConfig`。

| 本阶段结束累计次数 | 本阶段 cycles | 起始 duty 标准差 `initial_noise` |
|---:|---:|---:|
| 500 | 5 | 0.06 |
| 1000 | 5 | 0.005 |
| 1500 | 5 | 0.002 |
| 1700 | 2 | 0.001 |

每阶段从上一阶段全局最好 duty 重新建立粒子群，并重新使用 seed=7；
这是明确的 warm restart 协议，不是随机数状态完全连续的一次 1700 步
运行。无约束结果执行四阶段，500 nm 结果执行前两阶段。中间 checkpoint
保留 `optimized_duties.npy`、`pso_history.npy` 和 `summary.json`。
三个结构的泵浦均先在 0.5–8 nm 以 0.1 nm 扫描，再在最佳点附近 ±1 nm
以 0.01 nm 扫描；精扫保持在原边界内，过程静默。报告的最佳点均未落在
扫描边界。JSA 网格为 200×200，每轴 3470–3530 nm。

```bash
python -m tests.reproduce_qute --device cpu --min-domain-um 0
python -m tests.reproduce_qute --device cpu --min-domain-um 0.5 --stop-after 1000
```

脚本调用原 `run_pso.py`，没有再实现一套优化器。两条命令使用不同输出
目录，并拒绝覆盖已有非空协议目录。切换 CUDA 可以验证 GPU 分支，但
不同随机后端可能改变随机优化轨迹，不能要求复现小数点后每一位。

cost 不是最终纯度的单调替代量：无约束 500、1000、1500、1700 次的
Py_JSI 纯度依次约为 0.997530、0.997130、0.997530、0.997680；MSE 下降
过程中纯度可能回落。因此交付中保留实际 duty 与最终 JSA，不仅提供 cost。

### 5.3 可选局部回归与范围检查

500 nm 局部数值回归（明确不是纯 PSO）得到：

| 结构 | 最优 pump FWHM / nm | Py_JSI 口径纯度 |
|---|---:|---:|
| periodic | 2.42 | 0.8639774052 |
| erf initial | 2.80 | 0.9801800828 |
| L-BFGS-B optimized | 3.76 | 0.9991337707 |

该解最短 domain 为 0.5 µm；相对标准 PPLN 的峰值强度约为 26.79%。
同一泵浦下保留复 PMF 得到 0.9975313355。因此不能把主指标 0.999134
直接称为所有相位效应均已计入的纯度。

窗口/网格检查（同一个 500 nm 局部回归结构、同一 3.76 nm 泵浦）：

| 两轴总窗口 / nm | 网格 | Py_JSI 口径纯度 | 保留复 PMF |
|---|---:|---:|---:|
| 60 | 200×200 | 0.9991337707 | 0.9975313355 |
| 60 | 400×400 | 0.9991385027 | 0.9975360659 |
| 120 | 400×400 | 0.8358798762 | 0.8341189649 |
| 240 | 800×800 | 0.7796193873 | 0.7778928306 |

加密网格基本稳定，但扩窗后明显下降。因此此解并不是宽谱、无滤波的
高纯度源；60 nm cost 以外的结构未被约束。指定 60 nm 窗口相当于明确
报告观测/收集窗口，不应偷偷把裁剪后的结果当成全谱结果。后续若要
设计无窄窗限制的实验源，必须扩展 cost 和 JSA 的物理评价范围。

这一扩窗检查没有达到论文附录对宽窗口的数值。它排除了把 60 nm 主指标
直接外推到 120/240 nm 的说法，也保留了下一步物理复现的明确未通过项。
局部回归目录保留原运行记录；相位与窗口复核作为独立后处理记录，不将其
伪写为原优化时同步取得的数据。

### 5.4 自动与独立验证

`python -m tests.test_model` 在当前 CPU 环境结果为 **15 passed、1 skipped**。
跳过项是实际 CuPy/GPU 对照，本环境没有可用 CUDA。已通过项覆盖逐 domain
数值积分、零失配极限、PMF/cost 一致性、制造边界、PSO 历史、Py_JSI 约定、
默认值读取，以及明确要求 CUDA 但无设备时必须报错。

这些测试能检查实现与定义是否一致，不能替代论文全谱数据的实验/数值复现。

## 6. 使用范围

固定脉宽得到的 `sigma_z` 与长度来自一阶色散、变换极限高斯泵浦近似。
它提供合理起点，不代替最终带宽寻优。输出使用扫描后的最优带宽，初始
脉宽和带宽仍保留在 `geometry` 中供追溯。

以后改为 3.12 µm、60 fs 时，泵浦带宽和 JSA 范围都会明显变大：不要沿用
本 QUTE 基准固定的 0.5–8 nm pump scan 和 60 nm JSA 窗口。应在子模块
`JSAConfig` 修改范围，或用主程序的同名 CLI 参数覆盖，再做窗口/网格收敛
检查。若最优值落在扫描端点，summary 会标记 `pump_optimum_at_scan_boundary`。

当前环境没有 CuPy/CUDA；CPU 回归可验证，完整 GPU 数值测试在这里明确
跳过。用户 RTX 4090 上可运行 `python -m tests.test_model`，GPU 对照测试
将实际执行。旧上传结果已记录 `device: cuda`，无需仅因日志格式不同就
认为以前没有使用 GPU。
